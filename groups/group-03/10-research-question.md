#  Questões de Pesquisa

O desenvolvimento do projeto será orientado pelas seguintes questões de pesquisa:

### Questão de Pesquisa 1 — Problema e objetivo do sistema

*Qual problema de monitoramento o projeto pretende resolver e como o processamento MISD pode contribuir para essa solução?*

### Questão de Pesquisa 2 — Dados de entrada

*Quais dados devem ser coletados pelo sistema e como eles serão utilizados para representar o funcionamento do projeto?*

### Questão de Pesquisa 3 — Coleta dos dados

*Como o sensor de temperatura será conectado ao ESP32 e como os dados serão coletados pelo protótipo?*

### Questão de Pesquisa 4 — Comunicação

*Como os dados coletados pelo ESP32 serão enviados ao computador para serem processados?*

### Questão de Pesquisa 5 — Aplicação do MISD

*Como o mesmo dado coletado pelo sensor poderá ser utilizado por diferentes processos de análise no projeto?*

### Questão de Pesquisa 6 — Implementação do processamento

*Como os diferentes processos de análise serão implementados para trabalhar sobre o mesmo dado de entrada?*

### Questão de Pesquisa 7 — Armazenamento

*Como os dados coletados e os resultados das análises serão armazenados para permitir consultas e comparação com informações anteriores?*

### Questão de Pesquisa 8 — Apresentação dos resultados

*Como os resultados das diferentes análises serão apresentados ao usuário de forma simples e compreensível?*

### Questão de Pesquisa 9 — Testes e validação

*Como testar o protótipo para verificar se a coleta, transmissão, processamento e análise dos dados estão funcionando corretamente?*
