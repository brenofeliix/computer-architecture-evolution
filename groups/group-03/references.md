# Referências — Grupo 03

Este arquivo reúne as fontes acadêmicas e técnicas consultadas para o estudo da taxonomia de Flynn, das características da plataforma ESP32 e da linguagem Python utilizada no protótipo de monitoramento de temperatura.

## 1. Taxonomia de Flynn e organização de computadores

**FLYNN, Michael J.** Some Computer Organizations and Their Effectiveness. *IEEE Transactions on Computers*, v. C-21, n. 9, p. 948–960, 1972.

Disponível em: https://doi.org/10.1109/TC.1972.5009071

Acesso em: 19 out. 2026.

**Utilização no projeto:** referência acadêmica para estudar a classificação de organizações computacionais e o contexto histórico da taxonomia de Flynn.

## 2. Documentação técnica do ESP32

**ESPRESSIF SYSTEMS.** ESP32 Series Datasheet. Documentação técnica oficial da família ESP32.

Disponível em: https://www.espressif.com/sites/default/files/documentation/esp32_datasheet_en.pdf

Acesso em: 19 out. 2026.

**Utilização no projeto:** consulta às características do ESP32 original, incluindo processador, memória, conectividade e interfaces de entrada e saída. As especificações definitivas deverão ser conferidas conforme a variante utilizada pela equipe.

## 3. Documentação oficial do módulo ESP32-WROOM-32

**ESPRESSIF SYSTEMS.** ESP32-WROOM-32 Datasheet. Documentação técnica oficial do módulo ESP32-WROOM-32.

Disponível em: https://documentation.espressif.com/esp32-wroom-32_datasheet_en.html

Acesso em: 19 out. 2026.

**Utilização no projeto:** referência complementar para consultar características do módulo, interfaces de comunicação, recursos de memória e conectividade. Esta referência é específica do ESP32-WROOM-32 e não deve ser aplicada automaticamente a outras variantes.

## 4. Documentação oficial da linguagem Python

**PYTHON SOFTWARE FOUNDATION.** Python 3 Documentation. Documentação oficial da linguagem Python.

Disponível em: https://docs.python.org/3/

Acesso em: 19 out. 2026.

**Utilização no projeto:** consulta à sintaxe, aos recursos da linguagem e à documentação necessária para desenvolver o programa responsável pelo recebimento e pela análise dos dados de temperatura.

---

## Observação metodológica

As referências técnicas descrevem os recursos de hardware e software utilizados como base para o protótipo. Elas não demonstram, por si só, que o ESP32 implementa uma arquitetura MISD física. A relação com o MISD deve ser discutida a partir da definição arquitetural e das características efetivamente implementadas e testadas pela equipe.
